How to Use My Instruction

Use this workflow whenever you want to transform specific elements of an existing video without changing everything else.

What can you change?
You can use the instruction for environment changes, outfit changes, or other specific visual edits. The key idea is to clearly define what should change and what must stay unchanged in the original video.

How do you write a Seedance 2.5 prompt so the edit works as intended?

1

Go to ChatGPT or Claude

Upload the prompt engine together with two photos, in this order: first a screenshot of the original video frame, before any change; second the visual reference you want the edit to follow.

Then send this request:

Study and strictly follow the attached Seedance 2.5 instructions. Create the final prompt. @Video1 — the source video; the first photo is a screenshot from the original video. @Image1 — the visual reference [brief description: woman in a blanket, in the mountains]. Follow the format and rules from the instructions.

Replace the text inside the brackets with a short description of your own reference.

You get back the finished Seedance 2.5 prompt.

Creating a reference image
When you need a visual reference, you can prepare it in ChatGPT Image first. For example, take a screenshot from your original video and describe the environment, outfit, lighting or other visual changes you want to create.
2

Go to Seedance 2.5

Upload your original video + the reference image or images.

Paste the prompt you generated in ChatGPT and generate the edited video.

The same workflow works for background changes.
You can change the environment while keeping yourself, your performance and the original camera setup intact.
